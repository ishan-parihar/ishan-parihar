## Featured Projects

### ⚡ [icode](https://github.com/ishan-parihar/icode)
**Rust-native AI coding harness** — 48,599 LOC across 9 crates. Memory-safe agent runtime with tool orchestration, mock Anthropic API testing (10 scenarios), MCP server lifecycle management, LSP client dispatch, and permission enforcement.

### 🏗️ [AI-CAD](https://github.com/ishan-parihar/AI-CAD)
**AI-powered architectural design platform** — FastAPI backend generating floor plans from natural language, with ezdxf-based DXF export, real-time collaborative frontend, and 3D viewer. Full pipeline: NLP → spatial reasoning → CAD generation.

### 🎙️ [SOVEREIGN](https://github.com/ishan-parihar/SOVEREIGN)
**Voice-coached workout system** — Python LifeOS with Kokoro TTS (local ONNX neural model, 54+ voices), 4-tier audio caching (100+ WAV files, <0.1s latency), adaptive training algorithms (autoregulation + progressive overload), Rich terminal dashboard, checkpoint persistence.

### 🔍 [OSINT-OS](https://github.com/ishan-parihar/OSINT-OS)
**Multi-agent OSINT investigation platform** — CLI-driven intelligence gathering with premium search, DuckDuckGo/Google scraping, structured investigation reports, and Kubernetes-ready deployment architecture.

### 📊 [MT5-mcp](https://github.com/ishan-parihar/MT5-mcp)
**MetaTrader 5 MCP Server** — Trading infrastructure with market regime detection, ATR-based position sizing, bracket orders, trailing stops, and full trading decision support. Published as an MCP package.

### 🎬 [CineSync](https://github.com/ishan-parihar/CineSync)
**Automated video production pipeline** — Lip-syncing, emotion-based shot selection, and video generation with Docker-compose deployment.
